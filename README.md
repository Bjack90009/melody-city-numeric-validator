## 当前默认设置

2026-09-15：初始体力999，默认勾选“跳过表演过程”，31件道具、六级、固定朝向。
已有存档保留当前体力；新建/重置模式使用初始值。可在“参数与规则→参数”直接修改已有进度的剩余体力。旧默认配置中的初始18自动迁移到999，其他手动改值保留。取消勾选可恢复实时表演。

## 共同维护数值

| 文件 | 用途 |
| --- | --- |
| 爱乐之城-数值验证配置.xlsx | 可编辑数值表，仅包含本验证器的道具/规则/套装与说明 |
| data.json | 完整默认配置的维护源：items[].base六级基础，effect三档实际效果，rules规则，sets套装 |
| data.js | 网页实际加载配置，由同步脚本生成 |
| engine.js | 公式、技能条件和结算实现 |
| app.js / index.html / styles.css | 页面交互、导入验证、默认勾选及布局 |
| scripts/sync-data.cjs | 从data.json同步网页配置和Excel；可将网页导出的参数固化为默认值 |
| verify.cjs | 数值回归检查 |

### 直接修改 JSON

修改 data.json 后运行 `npm run sync:data`，它同时更新 data.js 和数值Excel。然后 `npm test`，在浏览器验证后提交全部变更。没有额外npm依赖，脚本使用仓库内xlsx库。

### 使用 Excel 调整

先另存一份Excel编辑。网页“参数与规则→模拟与Excel→加载数值Excel”，检查体验后在“案例与存档→导出布局与参数”。将导出的JSON保存在本机仓库外，运行：

```sh
node scripts/sync-data.cjs --from-save "导出的布局与参数.json"
npm test
```

脚本只提取data，不将个人存档写入仓库；不要整份存档覆盖data.json。建议先 `git diff` 检查数值变化，再提交 data.json、data.js 和 Excel。脚本会重新生成仓库里的Excel，因此人工修改先另存并导入，避免被覆盖。

基础值每级成长；效果只在1/3/6级换档，2级同1级，4/5级同3级。装扮0.003代表0.3%，木琴1代表1个百分点。只维护实际效果，不重算原表测算区。中提琴10/19/31等已确认测试值仍保留。

数量、形状、棋盘、最高等级受app.js校验约束；效果逻辑部分按ID实现，改描述不等于改机制。结构变化需同步程序与测试。数值测试包含当前基线断言，调整规则后应同步预期，不能为通过测试直接删断言。

## 发布与缓存

成员建分支修改，经PR合并main后Pages自动构建。检查Actions/Pages构建状态及公网release.json后再分享。每次发布更新release.json。
页面编辑/导入仅保存在当前浏览器；它不会自动提交Git，也不会更新其他人的默认值。已有本地配置会优先于网站默认值，验证新默认配置建议无痕窗口，或导入最新数值Excel；不要擅自清除用户存档。

当前仓库及页面暂时公开，仅包含验证器专用数值配置，不包含原始工作簿的其他业务分页、高清母图或个人试玩存档。旧版及V2独立保留。
